# Source Gate

將來源按責任面而非固定總排名比對：PRD 商業流程、RA 決策、Figma 可見 UI、API request/response、RBAC 角色／動作。
每筆記 reference、version/date、實際已讀內容、覆蓋的 condition 與 owner。link 存在不等於已讀。
- Source Gap：來源未定義某行為。
- Conflict：兩個有效來源對同一條件給出不相容結果。
- Version Mismatch：來源不屬於同一版本或 phase。
保留雙方 evidence 交 owner 決策；不能自行挑較容易執行的一方。未知精度、enum、mapping、permission 不補值。
