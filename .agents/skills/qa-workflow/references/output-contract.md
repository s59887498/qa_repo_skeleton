# Output Contract

每次交付列 Mode/Gate、scope/版本、outputs、實際 validation commands/results、evidence、defects、未執行範圍、blockers/risks、next owner/action。
Plan 要有策略/估算/進出條件；Cases 要有唯一 ID/可操作 steps/來源；Execution 要有逐案 actual/result/evidence；Automation 要有 mapping/runner/cleanup；Report 要有互斥統計/限制/缺陷。
模板範例與正式需求區分；本機框架測試通過不等於產品驗收。文件輸出、人讀 review、正式交付是不同完成點。
路徑都從 repo 根目錄表示。執行或報告交付依 operations/README.md 留下跨 turn 摘要。
