# 測試進度 — 待填模板

- Project / feature / version：待填
- Run ID / owner：待填
- Environment / build：待確認
- Recorded at / observed at / timezone：待填
- Stage / Gate / scope（run 或 project）：待填
- Case IDs / mutually exclusive counts：待填；全量未知勿填零
- Outputs / evidence：相對路徑或已確認的來源識別
- Defects / tracker destination：待填；未設定時為本機 Draft
- Blockers / risks / unexecuted scope：待填
- Cleanup / remaining resources：待填
- Test completion / report created / delivered / approved：各自列日期與證據
- Next owner / next action：待填
- Corrections to earlier runs：引用原紀錄，不覆寫
