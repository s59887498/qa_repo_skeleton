# 測試計劃 — 待填模板

## 1. 目的與來源
專案、版本、需求來源/版本、owner、Source Gap / Conflict / Version Mismatch。
## 2. 範圍
In scope、out of scope、功能／整合／非功能、風險與優先級。
## 3. 策略與覆蓋
Requirement → condition → technique → case/evidence lane；人工與自動化分工。
## 4. 環境與測資
目標 profile、access reference、資料建置、資源隔離、cleanup 與 dependency。
## 5. 進出條件
Readiness、執行條件、停止條件、缺陷門檻與 Release review 條件。
## 6. 排程與估算
任務、owner、區間估算、假設、依賴；不把猜測當承諾日期。
## 7. 交付與追蹤
Test Cases、execution evidence、Bug、報告、進度交接與未決事項。
