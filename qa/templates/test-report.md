# 測試報告 — 待填模板

## 1. 專案與版本
Environment、build、測試期間、來源版本、執行者。
## 2. 已測範圍與限制
Run / project scope、Case IDs、未執行／受阻範圍與原因。
## 3. 結果統計
唯一 Case ID；Passed / Failed / Blocked / Skipped / Not Started 互斥，總數一致。
## 4. 缺陷摘要
Severity、重現條件、影響、tracker 或 Draft reference、複驗 evidence。
## 5. Evidence 與 Cleanup
執行 command、JUnit/JSON/log、測資清理、仍保留的資源。
## 6. 風險與建議
基於實測的風險；Release 建議與核准分開，未確認項目不寫 PASS。
## 7. 交付與簽核
報告建立、review、交付、approval 日期與 owner；文件存在不等於已交付。
